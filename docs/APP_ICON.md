# Miro: Last Man Standing app icon

`assets/icons/miro_app.png` is a full-body icon based on the user-supplied enlarged Miro sprite reference. It preserves the distinctive cream-and-peach mask markings, dark U-shaped upper marking, mauve hood, flared cloak and thin legs. These markings follow the supplied design and do not establish a skin tone. The source character sprite remains unchanged. `miro_app.ico` packages the icon at 16, 32, 48, 64, 128 and 256 pixels. Pillow is used solely for ICO size encoding.

`project.godot` supplies the generic icon and Windows native taskbar icon. Both Windows export presets enable resource modification, set the executable icon and brand the file metadata as Miro: Last Man Standing. The internal project name remains Miro so existing local save storage is preserved.

Build with `Build Windows.ps1`; validate with `Check Windows Build.ps1`. The release ZIP contains the self-contained `Miro.exe` at its root. On the author's PC it is saved at `C:/Users/ethan/Miro/build/Miro-Playtest-Windows.zip`. The desktop Miro Play shortcut targets that checkout's `build/windows/Miro.exe` and uses `assets/icons/miro_app.ico`.

Validation: all five exported floor startup checks passed; the icon was extracted from the exported executable and visually checked, and its product name/file description are Miro: Last Man Standing.

Generation: built-in image-generation tool, using the user's enlarged sprite screenshot as the visual reference. Final prompt:

> Create a square app icon using EXACTLY the Miro pixel sprite shown in this attached image. Treat this as a precise reference-preserving composition, NOT a character redesign. The image shows the full standing Miro sprite on gray checkerboard within a dark surrounding screenshot. Remove the screenshot frame and gray checkerboard; replace those with a flat deep aubergine #272744 icon background, with a very thin muted-purple square border inset. Reproduce the central character faithfully, full body centered with a small safe margin: same sharply stepped outline, same right-facing cream rectangular mask with peach square markings (these are the reference MASK DESIGN, do not reinterpret as human skin), tiny vertical black rectangular eye, dark U-shaped upper mask marking with muted purple inset, same dark mauve hood projecting back left, same high-neck muted dusty mauve triangular cloak flaring at its ragged dark-violet hem, same two skinny straight dark legs. Preserve every distinctive proportion and silhouette, and the original small square pixel grid. No invented hair, no realistic face anatomy, no exposed skin, no glowing eyes, no hands, no weapons, no tower, no scenery, no portrait crop, no lighting gradients, no glow, no extra details or shading. It must look like the exact attached in-game Miro sprite enlarged with nearest-neighbor pixels, sitting in a clean square app icon. Flat limited original sprite colors, hard square pixel clusters. No text or letters. The full sprite should occupy about 80 percent of the square height. Fidelity to this sprite is the primary requirement.

Configuration follows the [Godot 4.7 Windows icon guide](https://docs.godotengine.org/en/4.7/tutorials/export/changing_application_icon_for_windows.html).
